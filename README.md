# Финансовый аналитический сервис

Проект представляет собой backend-сервис для анализа финансовых операций пользователя. Он обрабатывает данные транзакций и формирует JSON-ответы для отображения на различных страницах (например, главная страница и страница событий).

---

## Функциональность

### Главная страница (`main_page`)
Возвращает:
-  Приветствие в зависимости от текущего времени:
    - Доброе утро
    - Добрый день
    - Добрый вечер
    - Доброй ночи
-  Информацию по картам:
    - последние 4 цифры
    - сумма расходов
    - кэшбэк (только для расходов)
-  Топ-5 транзакций
-  Курсы валют
-  Цены акций

---

### Страница событий (`events_page`)
Возвращает:
-  Расходы:
    - общая сумма
    - топ-7 категорий
    - переводы и наличные отдельно
-  Доходы:
    - общая сумма
    - категории доходов
-  Курсы валют
-  Цены акций

## Запуск проекта

1. Установить зависимости:
```
bash
pip install -r requirements.txt
```
2. Указать API-ключи в коде или переменных окружения:
- API_KEY_CURRENCIES
- API_KEY_STOCKS
3. Запустить:
`python src/main.py`

## Тестирование
Запуск тестов:
`pytest`

## Важные замечания
- Кэшбэк рассчитывается только для расходов (отрицательные значения)
- Курсы валют могут не загружаться при:
  - невалидном API-ключе
  - отсутствии доступа к API
- При ошибках API возвращается пустой список
